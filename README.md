# VisionRAG

Advanced Multimodal Retrieval-Augmented Generation System with OCR, Vision AI, Real-Time Web Search, and Intelligent File Generation.

## Features

- PDF understanding
- OCR support
- Embedded image analysis
- Semantic retrieval
- Real-time web search
- Citation-aware responses
- Intelligent file generation
- Multimodal RAG pipeline

## Tech Stack

- FastAPI
- Streamlit
- FAISS
- Groq API
- Tesseract OCR
- EasyOCR
- Sentence Transformers
- Tavily Search
